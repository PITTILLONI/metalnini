Activer la double authentification

Obligatoire pour l'admin. Ton téléphone génère un code à 6 chiffres qui change toutes les 30 secondes ; tu le saisis ici à chaque connexion.

Ne recharge pas cette page avant d'avoir validé : chaque chargement crée un nouveau QR code, et l'ancien ne marche plus.

  1. Sur iPhone, sans rien installer : ouvre l'app Mots de passe → Codes → + → Scanner le QR code (ou Saisir la clé de configuration et colle la clé ci-dessous). Nomme l'entrée « Metalnini admin ».
  2. Ou avec Google Authenticator : + → Scanner un QR code.
  3. Saisis ici le code à 6 chiffres affiché dans l'app, puis Valider.
