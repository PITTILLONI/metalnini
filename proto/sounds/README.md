# Sons du prototype

Déposer ici des fichiers **MP3** portant exactement ces noms. Chaque fichier présent remplace le son synthétisé correspondant ; un fichier absent garde la synthèse.

| Fichier | Moment | Durée conseillée |
|---|---|---|
| `tear.mp3` | Déchirure du sachet | < 0,5 s |
| `flip.mp3` | Retournement d'une carte | < 0,3 s |
| `commune.mp3` | Révélation d'une Commune | < 0,5 s |
| `rare.mp3` | Révélation d'une Rare | ~1 s |
| `holo.mp3` | Révélation d'une Holo | ~1,5 s |
| `signature.mp3` | Révélation d'une Signature | ~2 s |
| `legendaire.mp3` | Révélation d'une Légendaire | 2 à 3 s |
| `build.mp3` | Montée en tension avant une Signature ou une Légendaire (double pédale) | ~2,5 s |
| `heartbeat.mp3` | Battement de cœur à l'ouverture d'un paquet Légendaire | < 0,5 s |
| `land.mp3` | Carte rangée dans le classeur | < 0,4 s |
| `complete.mp3` | Classeur complété | ~2 s |

Conseils : sons courts, sans silence au début, niveaux homogènes entre eux (normaliser vers -1 dB), mono ou stéréo, 44,1 kHz. Uniquement des sons dont on a les droits (enregistrés soi-même ou sous licence libre).
